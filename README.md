## Flagship project: 9eye

**[9eye](https://github.com/mrtero22/9eye)** — open-source broadcast scheduling and TV traffic software
with AI agents built in: media catalog, layouts, scheduling, frame-accurate playlists, ad booking and
export to playout, plus an MCP server and a team of agents that work under the same permissions as
people.

<a href="https://github.com/mrtero22/9eye">
  <img src="https://raw.githubusercontent.com/mrtero22/9eye/main/docs/images/scheduling-plan.png" alt="9eye Scheduling: a series plan on a channel's week" width="100%">
</a>

TypeScript · React 19 · Express 5 · Prisma · PostgreSQL · Playwright · 300+ automated tests · AGPL-3.0

## What we build

| | |
|---|---|
| **Broadcast automation** | Playlist QC before playout, ad traffic that places itself, airing patterns rebuilt by an agent, export files your playout accepts |
| **AI agents and MCP servers** | Agents on Claude, ChatGPT or a local model that do one job, connected to your systems through MCP, with a person approving what matters |
| **Validators and data checks** | Every file, export or playlist checked against your rules before it goes out, with a report that points to each problem |
| **Automation without an API** | Chrome extensions (Manifest V3) and browser automation inside the web apps your team already uses |
| **Integrations and pipelines** | Data typed twice today moving on its own between sales, traffic, spreadsheets and databases |
| **Private, local AI** | Speech-to-text, translation and classification on your own hardware, with no per-minute cloud bills |
